# RNA-LNP Formulation Design: An Uncertainty-Aware AI Prototype

**Author:** Ikechukwu Okechi Kamalu  
**Live application:** https://rna-lnp-closed-loop-designer-ccv5qvbjtnpcpq2rwckrtd.streamlit.app/  
**Repository:** https://github.com/ikechukwukamalu8/rna-lnp-closed-loop-designer

## Overview

This repository contains an interactive Streamlit proof of concept exploring how predictive modelling, stochastic candidate search, and conformal prediction can be combined in a computational workflow for lipid nanoparticle (LNP) formulation design.

**Important limitation:** the current implementation trains on simulated data generated by a mathematical formula in `app.py`. It does not train on experimental LNP measurements, and its predictions have not been biologically or experimentally validated. The app is for research and software demonstration only; it must not be used to select real formulations for synthesis, infer biological efficacy, or make therapeutic decisions.

## What is implemented

### 1. Synthetic-data generation

At startup, the app generates 1,000 simulated rows with four numerical features:

- `ionizable_lipid_ratio` (35–60 molar %)
- `particle_size_nm` (generated around 85 nm using a normal distribution)
- `zeta_potential` (-10 to 25 mV)
- `encapsulation_efficiency` (75–99%)

A hand-specified mathematical formula transforms these inputs into a synthetic `liver_transfection_efficiency` score scaled from 0 to 100. This score is a simulated target, not a measurement of real transfection.

### 2. Random Forest and XGBoost ensemble

Random Forest and XGBoost regressors are trained on a training subset of the synthetic data. The app averages their predictions to produce an ensemble score. Because both models learn from the same formula-generated target, this demonstrates the software workflow rather than predictive validity on biological data.

### 3. Stochastic inverse-search mode

When a user specifies a target score, the app samples 150 candidate parameter combinations within predefined ranges. It returns the sampled candidate whose ensemble prediction is closest to the requested score. This is a simple stochastic search, not a generative model, exhaustive optimisation, or search across millions of formulations. The returned values are numerical feature settings, not a complete chemical recipe: the implementation does not specify lipid identities, all formulation components, manufacturing conditions, or a validated synthesis protocol.

### 4. Split-conformal interval calculation

A calibration subset is used to calculate absolute residuals between the synthetic target and ensemble predictions. A quantile of these residuals is then added to and subtracted from a candidate prediction, with the displayed interval clipped to [0, 100]. The interface labels this a 95% interval. Its coverage has not been evaluated on a separate test set or real experimental data; the nominal target should not be interpreted as demonstrated 95% coverage in biological use.

### 5. Manual prediction mode and display

Users can adjust the four input features, view Random Forest, XGBoost, and averaged predictions, inspect the interval, and view a JSON summary of the selected inputs and outputs. The app also displays threshold-based status messages. These messages are illustrative software rules, not validated biological recommendations or instructions to synthesise a candidate.

## Workflow summary

```text
Formula-generated synthetic data
              ↓
       Training partition
              ↓
 Random Forest + XGBoost regressors
              ↓
     Averaged ensemble prediction
              ↑
  Stochastic search over 150 candidates
              ↓
 Calibration residual quantile → displayed interval
              ↓
       Streamlit dashboard
```

The code reserves 15% of the synthetic data in a holdout split, but that subset is not used to report model performance in the current implementation. The app does not ingest new laboratory observations, update models from experimental feedback, or implement an actual closed-loop design–test–learn process.

## Run locally

Python 3.10 or a compatible environment is recommended. Install the dependencies listed in `requirements.txt`, then run:

```bash
git clone https://github.com/ikechukwukamalu8/rna-lnp-closed-loop-designer.git
cd rna-lnp-closed-loop-designer
pip install -r requirements.txt
streamlit run app.py
```

## Limitations and next steps

Before this approach could inform real formulation research, it would require suitable experimental LNP data with documented formulation chemistry, assay definitions, biological context, and outcomes. Future work should include leakage-aware train/calibration/test design, evaluation on an untouched test set, external validation where available, assessment of interval coverage and width, distribution-shift analysis, and prospective laboratory testing. A genuine design–test–learn loop would also require validated ingestion of experimental results and an explicit model update/recalibration procedure.

## Intended use

This project is an educational and research software prototype demonstrating a possible integration of regression models, stochastic search, and conformal interval calculation. It is not a validated drug-discovery system, does not establish optimal LNP formulations, and does not replace laboratory experiments or expert scientific judgement.
